# PRACTISIM DESIGNER BAY PRESETS
Repository for sharing bay preset json files for use in Practisim Designer.

# HOW-TO
1. Download the preset json files that you want or clone this repository
2. In Practisim Designer, go to BAY, then MANAGE PRESETS
3. Then click on IMPORT PRESET and point it to the preset json file that you want
